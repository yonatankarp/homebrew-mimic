# Homebrew tap for Mimic

[Mimic](https://yonatankarp.com/mimic/) turns a picture or a description into a 3D-printable miniature.

```bash
brew install --cask yonatankarp/mimic/mimic
```

This installs the app and the `mimic` command. Mimic updates itself, so you don't need
`brew upgrade`. The cask is updated automatically when a Mimic release is published.
